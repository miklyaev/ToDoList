# ToDoList

Приложение для списка задач на HTML, CSS и нативном JavaScript.

## Структура

```text
.
|-- index.html              # Разметка приложения
|-- src/
|   |-- main.js             # Логика приложения: задачи, фильтры, поиск, навигация
|   `-- styles/
|       `-- main.css        # Стили интерфейса
└-- README.md
```

## Как запустить

Для локального запуска откройте проект через статический сервер, например Live Server в VS Code.

Подходит любой простой способ запуска веб-страницы, например:

```bash
python -m http.server
```

После этого откройте адрес, который покажет сервер в браузере.

## Что умеет приложение

- добавлять задачи;
- помечать их как выполненные;
- удалять задачи;
- искать по названию;
- фильтровать по статусам;
- сохранять данные в `localStorage` между перезагрузками.

## Примечание

В этом проекте нет ES-модулей: подключение JavaScript выполняется обычным скриптом, а не через `import`/`export`.
