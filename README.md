# ToDoList

Приложение для списка задач на HTML, CSS и нативном JavaScript с ES-модулями.

## Структура

```text
.
|-- index.html              # Разметка приложения
|-- src/
|   |-- main.js             # Точка входа и обработчики интерфейса
|   `-- styles/
|       `-- main.css        # Стили приложения
└-- README.md
```

## Запуск

Откройте `index.html` через локальный статический сервер, например Live Server в VS Code. ES-модули не следует запускать через `file://`.
